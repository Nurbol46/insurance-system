# Информационная подсистема страховой фирмы

Веб-сайт для проектирования и управления страховыми услугами: каталог, заявки, личный кабинет клиента и админ-панель.

## Технологии

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **База данных:** MongoDB

## Функциональность

### Пользовательская часть
- Главная страница
- Каталог страховых услуг
- Оформление страховки (онлайн-заявка)
- Личный кабинет клиента
- Просмотр статуса полиса
- Контакты компании
- Регистрация и вход

### Админ-панель
- Добавление и удаление страховых услуг
- Управление клиентами
- Просмотр заявок
- Одобрение / отклонение страховок
- Статистика

## Запуск проекта

### 1. MongoDB (необязательно)

Если MongoDB **не установлена**, сервер сам запустит встроенную базу при `npm start`.

Для постоянного хранения данных установите MongoDB и запустите её:

```bash
sudo systemctl start mongod
```

### 2. Установите зависимости

```bash
cd insurance-system
npm install
```

### 3. Запустите сервер

```bash
npm start
```

Откройте в браузере: **http://localhost:3000**
